# Catálogo de modos de voz en el Taller de melodías (idea, 2026-11-16)

Idea de Claudio, durante VOZ-3: la sección «Modo de voz» del Taller de melodías es hoy una fila de 11 chips. Que sea un **selector o una lista con buscador**, para probar muchos más perfiles y explorar la expresividad que Pink Trombone puede dar.

- Lista con buscador (por nombre, etiqueta, rasgo: growl, soplada, falsete, nasal…), agrupada por familias.
- Muchos más perfiles: estilos de canto reales (con fuente, como los de hoy), voces de personajes y extremos del motor (tracto 36–56, growl, aspereza, aire).
- Cada perfil se puede llevar al juego con «Copiar TV1» (VOZ-3), así que el catálogo del taller es también el catálogo de estilos posibles para las paletas de las cartas.

**Dónde va:** tangente, no es de VOZ-3. Candidata para después de la demo (bloque de voz del plan POST-DEMO, junto a DUET-1) o para una sesión extra de MidiGenPlay/taller si sobra una semana. Sin decidir.
