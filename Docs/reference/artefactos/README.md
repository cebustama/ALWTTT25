# Índice de artefactos de ALWTTT

Página publicada: https://claude.ai/artifact/LqBXmAVoV4Vs3pzPzqy6ZA (privada; creada el 2026-11-06).

`indice-artefactos.html` es la fuente. Los datos están en la lista `ITEMS` del final del fichero: nombre, enlace, qué es, fecha de última modificación e hilo (`plan`, `ui`, `reglas`, `musica`, `ref`, `rel`).

## Cómo se mantiene

Al cerrar una sesión que crea o cambia un artefacto de ALWTTT:

1. Actualizar la fila (o añadirla) y `AS_OF`.
2. Publicar el mismo fichero con la URL de arriba, para no crear otra página.

Las fechas salen de la lista de artefactos de claude.ai (`Artifact`, `action: "list"`). No es autoridad: el plan y los SSoT mandan.
