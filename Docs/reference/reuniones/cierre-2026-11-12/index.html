La telemetría funciona, pero solo en local

Escribe una línea JSON por concierto terminado (resultado, canciones, loops, alineación, público y cada carta jugada). En el editor va a ALWTTT25/DevTelemetry/ (30 conciertos desde el 16-jul). En la build va a %USERPROFILE%\AppData\LocalLow\DefaultCompany\ALWTTT25\DevTelemetry\. No se manda a ningún sitio: para tenerla, el tester la adjunta. Depende del símbolo ALWTTT_DEV, que también deja abierto el Dev Mode (F12) en la build.
